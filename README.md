# English with Alex

Landing page responsiva desenvolvida como parte da Produção Textual Individual (PTI).

O projeto apresenta os serviços fictícios de um professor particular de inglês, com informações sobre o professor, metodologia de ensino, planos, preços e formas de contato.

## Sobre o projeto

A proposta da atividade consiste no desenvolvimento de uma landing page para um profissional autônomo ou empresa de pequeno porte.

Para o projeto, foi escolhido o ramo de ensino de idiomas e criado o **English with Alex**, uma página fictícia para divulgação dos serviços do professor particular Alex Martins.

A página foi desenvolvida pensando em adultos iniciantes no inglês que procuram aulas particulares online e um ensino personalizado.

O conceito visual utiliza o slogan:

> English for your next chapter.

## Objetivo

O objetivo do projeto é aplicar na prática os conceitos estudados de desenvolvimento web, criando uma página que:

- apresente um serviço de forma clara;
- destaque características e benefícios;
- apresente opções de contratação;
- incentive o usuário a entrar em contato;
- possua formulário de contato;
- seja adaptável a diferentes tamanhos de tela.

## Estrutura da página

A landing page foi organizada nas seguintes seções:

- **Início:** apresentação principal do serviço e chamadas para ação;
- **Sobre:** apresentação do professor e seus diferenciais;
- **Metodologia:** explicação do método de ensino A.S.T.R.A;
- **Preços:** apresentação dos planos e valores;
- **Contato:** informações para contato e formulário;
- **Footer:** navegação complementar, redes sociais e informações do projeto.

## Tecnologias utilizadas

O projeto foi desenvolvido utilizando somente:

- HTML5
- CSS3
- Flexbox
- Media Queries

Não foram utilizados JavaScript, frameworks CSS ou bibliotecas externas para construção do layout.

## Responsividade

A página foi desenvolvida para funcionar tanto em telas maiores quanto em dispositivos móveis.

A responsividade foi construída manualmente utilizando **Media Queries**, com breakpoint principal em `600px`.

Entre as adaptações realizadas para dispositivos móveis estão:

- reorganização de layouts horizontais para verticais;
- redimensionamento de imagens;
- reorganização dos cards de preços;
- adaptação da área de contato e formulário;
- reorganização do rodapé;
- ajustes de tipografia e espaçamento;
- preservação de áreas de interação adequadas em botões e links.

## Como executar

O projeto não necessita de instalação de dependências ou ferramentas adicionais.

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

Por utilizar apenas HTML e CSS, a página pode ser executada diretamente no navegador.

## Requisitos da atividade

O projeto foi desenvolvido a partir da proposta da Produção Textual Individual, que solicita:

- escolha de um ramo de negócio de pequeno porte ou profissional autônomo;
- prototipação de uma landing page;
- implementação utilizando HTML e CSS puros;
- utilização de Flexbox;
- no mínimo cinco faixas de conteúdo;
- apresentação da empresa ou profissional e seus serviços;
- vantagens e benefícios;
- chamada para contato;
- formulário;
- layout responsivo para acesso por dispositivos móveis;
- publicação da página em uma plataforma de hospedagem.
